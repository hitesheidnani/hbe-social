Charts from creators who gave permission (see content/chart_partners.json).

Add an image to `inbox/` named `<x handle> - <short title>.png` (or .jpg), e.g. `Banana3Stocks - Nasdaq breadth.png`.
Optional: a text file with the same name (.txt) holding one or two lines about the chart.
One chart a day is posted at 14:00 IST with credit, then moved to `used/`. Only handles listed in
chart_partners.json are posted.
